# 🤖 Depression Detection Chatbot using DistilBERT

This project is an AI-powered tool designed to detect signs of depression from text input. It uses a fine-tuned **DistilBERT** (Transformer) model and is deployed as a web application via **Streamlit**.

## 🚀 Key Features
* **High Accuracy:** Achieved a test accuracy of **97.77%**.
* **Transformer-based:** Built using Hugging Face's `TFDistilBertForSequenceClassification`.
* **Real-time Interface:** Simple and interactive UI for text analysis.

## 📊 Performance Results
* **Test Accuracy:** 97.77%
* **Precision/Recall:** ~0.98 for both classes (Depressed/Not Depressed).
* **Training History:** Loss and accuracy plots are included in the repository.

## 🛠️ Tech Stack
* **Language:** Python
* **Deep Learning:** TensorFlow, Transformers (Hugging Face)
* **Web Framework:** Streamlit
* **Data Handling:** Pandas, NumPy, Scikit-learn
